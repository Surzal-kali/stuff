# nvim scratch buffer lane (F2 → pyright, via generated tool stubs)

The F2 escape hatch (`tool_repl.py` cell → external editor) becomes a real
editing surface: nvim (LazyVim) attaches **pyright** to the temp cell, which
resolves the REPL's runtime-injected tool aliases from generated stubs — so
scratch cells get completion, hover (`K`), and signature help on `(` for
framework tools.

The tool wrappers only exist at runtime (`build_ipython_namespace` mints one
`async def` wrapper per discovered tool into the IPython `user_ns`), so the
editor can't see them by static analysis alone. This lane closes that gap.

> **Additive-only invariant:** every piece below is either a new file or a new
> line in a config file. `tool_repl.py` and `daharness/*` are never edited —
> the generator reads framework code, writes nothing back.

The stub dir is disposable by design: it is fully derivable from the repo via
the generator. Nothing in it is hand-written, so git-tracking it would only add
drift.

## Stub dir inventory (`~/.local/share/framework-stubs/`)

### `framework_tools.py` — PEP 562 shim (runtime side)

- Module docstring with the generation stamp (`Generated by scripts/gen_repl_stubs.py …`, date, tool count).
- `__all__` — every alias in sorted order (one per REPL-injected wrapper).
- `__getattr__(name)` — PEP 562 module hook:

  ```python
  def __getattr__(name: str) -> Any:
      _get_ip = getattr(builtins, "get_ipython", None)
      _ip = _get_ip() if _get_ip else None
      if _ip is not None and name in _ip.user_ns:
          return _ip.user_ns[name]
      raise AttributeError(...)
  ```

  `get_ipython` is a builtin only inside IPython, so inside the REPL every
  `__all__` entry resolves to the **live** wrapper; outside the REPL access
  raises a descriptive `AttributeError` instead of returning a silent `None`.
- No implementations. pyright types from the same-name `.pyi`; this file exists
  so `from framework_tools import *` executes clean in the REPL.

### `framework_tools.pyi` — type declarations (editor side, pyright consumes this)

One `async def` per alias, sorted:

```python
async def amass(target: str, options: str = None, scope_handle: str = None, scope_platform: str = None, **kwargs: Any) -> Any: ...
    """<verbatim _build_docstring output: capability, tool_id, transport,
    path, tags, Parameters, Next steps>"""
    # handles: ... | tags: recon.subdomain
```

- Signatures come from `tool_repl._build_signature` (required params first, no
  default; optional params default `None`), **plus `**kwargs: Any`
  permissively** — unknown kwargs go through preflight validation and get
  rejected there, but discovery occasionally surfaces params the static schema
  pass misses. Dropping `**kwargs` later is a free tightening (static arg-name
  checking) with no call-site churn.
- Docstrings are `tool_repl._build_docstring` verbatim — the same text
  `tool?` prints in the REPL.
- A one-line trailing comment carries `accepted_handle_kinds` and category
  tags for visual grep.
- Header: generation date (UTC), tool count, do-not-edit stamp.

## Regeneration

```bash
cd ~/github/stuff
./venv/bin/python scripts/gen_repl_stubs.py          # regenerate + print summary
./venv/bin/python scripts/gen_repl_stubs.py --check  # exit 1 if stale (CI-able)
FRAMEWORK_STUBS_DIR=~ elsewhere python scripts/gen_repl_stubs.py   # custom output dir
```

- Path taken: `tool_repl.discover_tools()` (the full static+dynamic scan, **no
  ChromaDB needed**) → `tool_repl.build_tool_aliases(manifests)` **verbatim**
  (curated `_TOOL_ALIASES`, auto-derivation, collision qualification — reused,
  never reimplemented, so stubs can't drift from what actually executes) →
  `_build_signature` / `_build_docstring` per alias.
- The `__all__` list and the `.pyi` defs are always from the same alias map, so
  the two files can't disagree with each other or with the live namespace.

## Scratch-cell convention (the two-line header)

```python
# vim: ft=python
from framework_tools import *
```

1. **Modeline** — prompt_toolkit's F2 temp cell doesn't get a `.py` suffix, so
   the modeline is what gives the buffer a python filetype; without it no Python
   LSP attaches, and nothing in the stubs matters.
2. **Star-import** — getattr's each `__all__` entry inside the REPL, and each
   one resolves through `__getattr__` to the live wrapper in `user_ns`. The
   alias is already in `user_ns`, so this costs nothing at REPL time; it exists
   so pyright sees the names and the header import never raises.

Notes:

- F2 opens a **real temp file**, so pyright attaches fine. A truly *untitled*
  buffer would not get LSP — hence modeline-on-a-file, not `:set filetype`.
- The shell that launches the REPL exports
  `PYTHONPATH="$HOME/.local/share/framework-stubs"` (`~/.zshrc`) so the header
  import resolves at runtime. nvim/pyright needs only `extraPaths` (next
  section) — the zshrc line is purely the in-REPL execution path.

## nvim wiring (`~/.config/nvim/lua/plugins/python.lua`)

```lua
local stubs_dir = vim.fn.expand("~/.local/share/framework-stubs")

return {
  "neovim/nvim-lspconfig",
  opts = {
    servers = {
      pyright = {
        -- lazy.nvim deep-merges with the python-extra's spec; extraPaths
        -- lands in the same settings tree the extra already owns.
        settings = {
          python = {
            analysis = {
              extraPaths = { stubs_dir },
              diagnosticMode = "openFilesOnly",
            },
          },
        },
      },
    },
  },
}
```

- The LazyVim `lang.python` extra (already in `lazyvim.json` extras) enables
  `pyright` via Mason; this spec only extends its settings.
- Same-name `.py/.pyi`: pyright resolves types from the `.pyi` automatically.
- `diagnosticMode = "openFilesOnly"` keeps background analysis off — diagnostics
  stay scoped to buffers you're actually in (scratch cells, stub consumers).

## Sanity checks (post-regen)

1. Scratch cell with the header → typing `ssh_` blink-completes `ssh_connect`
   etc. from the `lsp` source; `ssh_connect(` pops the signature window.
2. `:LspInfo` → pyright attached (check `extraPaths` in the client config).
3. In a live REPL: `from framework_tools import *` → no error; an alias
   resolves with `__manifest__` present.
4. `K` on an alias → the manifest docstring.
5. Header timestamp changes after re-running the generator; `--check` exits 0.
